# Subhakamana Store Management System

## Simple Use Case Report for General Users

**System Name:** Subhakamana Store Management System  
**Purpose:** Online clothing store and inventory management system  
**Main Users:** Admin and Customer  
**Prepared Date:** July 7, 2026  

---

## 1. What This System Does

The Subhakamana Store Management System helps run an online clothing store.

It connects the customer website with the store inventory dashboard. This means customers can browse products and place orders, while the admin can manage products, stock, orders, customers, and reports from the admin side.

In simple words, the system helps with:

- Showing products online
- Letting customers place orders
- Managing products and categories
- Checking stock and inventory
- Managing orders
- Sending order notifications
- Viewing customer details
- Viewing business reports

---

## 2. Main People Who Use The System

There are two main users:

### Admin

The admin is the store owner or staff member who manages the business side of the system.

The admin can:

- Log in
- Add or update products
- Manage product categories
- Check inventory
- Manage customer orders
- View customer information
- Link the website with inventory
- Send order notifications
- View reports

### Customer

The customer is the person shopping from the online store.

The customer can:

- Register or log in
- Browse products
- Search products
- Add products to cart
- Place an order
- Track an order
- Receive order notifications

---

## 3. Admin Side Explained Simply

### Admin Login

Before the admin can do any store management work, they must log in.

This protects the system so only authorized people can manage products, orders, stock, and reports.

### Manage Products

The admin can add new products, edit product details, update prices, and remove products when needed.

Example:

If a new Kurta arrives, the admin can add its name, price, size, color, and stock quantity.

### Manage Categories

The admin can organize products into categories.

Example categories:

- Kurta
- Saree
- Dupatta
- Festival Wear

### Manage Inventory Dashboard

The admin can check stock levels from the inventory dashboard.

This helps the store know:

- Which products are available
- Which products are low in stock
- Which products are sold out
- Which products need to be reordered

### Manage Orders

The admin can view and update customer orders.

Example order stages:

- New order
- Packed
- Dispatched
- In transit
- Delivered

### View Customer Details

The admin can view customer information needed for orders and support.

This may include:

- Customer name
- Phone number
- Address
- Order history

### Link Website With Inventory Dashboard

This means the online website and inventory dashboard should use the same stock information.

For example:

If a product is sold online, the stock count should reduce in the inventory dashboard.

### Send Order Notifications

The admin can send updates to customers about their orders.

Examples:

- Order confirmed
- Order packed
- Order dispatched
- Order delivered

### View Reports

The admin can view reports to understand the business.

Reports may show:

- Total sales
- Popular products
- Low stock products
- Customer orders
- Delivery status

---

## 4. Customer Side Explained Simply

### Register / Login

Customers can create an account or log in to shop more easily.

This can help them track orders and save their details.

### Browse Products

Customers can look through available clothing items on the website.

### Search Products

Customers can search for products by name.

Example:

A customer may search for “red saree” or “blue kurta.”

### Add Items To Cart

Customers can add products they want to buy into the shopping cart.

The cart stores selected products before checkout.

### Place Order

Customers can place an order after adding products to the cart.

They provide:

- Name
- Phone number
- Delivery address
- Payment method

### Track Order

Customers can check the status of their order.

They can see whether the order is packed, dispatched, in transit, or delivered.

### Receive Order Notifications

Customers receive updates about their order.

For example:

If the admin updates an order as dispatched, the customer can receive a notification.

## 5. Important Relationships In The Diagram

### All Admin Work Requires Admin Login

The diagram shows that all admin functions require **Admin Login**.

This means the admin must log in before doing tasks like managing products, orders, inventory, categories, customers, and reports.

### Place Order Includes Receive Order Notification

When a customer places an order, the system should send an order notification.

Example:

After placing an order, the customer may receive a message saying:

“Your order has been placed successfully.”

### Manage Orders Includes Send Order Notifications

When the admin manages an order, they may send notifications to the customer.

Example:

If the admin marks the order as dispatched, the system can notify the customer.

This system is useful because it keeps the online store and store management connected.

It helps Subhakamana Store:

- Reduce manual work
- Avoid stock confusion
- Track customer orders
- Keep product information organized
- Improve customer service
- View sales and inventory reports
- Send better order updates

## 7. Simple Example Of How The System Works

1. Admin logs in.
2. Admin adds a new Saree product.
3. Customer visits the website.
4. Customer searches for Saree.
5. Customer adds the Saree to cart.
6. Customer places an order.
7. Customer receives an order notification.
8. Admin sees the order in the dashboard.
9. Admin packs and dispatches the order.
10. Customer tracks the order until delivery.
