# Subhakamana Store Management System

Front-end prototype for a Nepali fashion and clothing store management system.

## Open First

Start with:

- `OPEN_THIS_FIRST.command`
- or `open-subhakamana-store-system.html`

## Included Platforms

- **Admin ERP** - `subhakamana-store-final-erp-platform.html`
- **Cashier POS** - `subhakamana-store-physical-pos.html`
- **Customer Website** - `subhakamana-store-ecommerce.html`
- **System Overview** - `subhakamana-store-simple-overview.html`

## Project Status

This is a local front-end prototype. It uses browser localStorage for demonstration data. Production use will require a backend API, database, secure login, payment gateway integration, image storage, and courier API integration.

The project can run locally without a domain. For the smoothest experience, open the local start page or run the provided `.command` launch file on macOS.
