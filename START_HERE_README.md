# START HERE - Subhakamana Store Complete System

This folder contains the complete Subhakamana Store system package.

The current browser system is still a front-end prototype for demonstration and academic/project presentation. A production database foundation has now been added under `production-readiness/module-01-database/`, but real login, live backend APIs, payment verification, inventory synchronization, courier tracking, notifications, and admin security still require the next production backend modules.

## Best Way To Open

Double-click:

**OPEN_THIS_FIRST.command**

It starts the local system and opens the main home page:

`open-subhakamana-store-system.html`

From there you can open:

- Customer shopping website
- Main ERP/store system
- Physical store POS system
- Simple overview
- User manual
- Physical POS guide
- Local use guide
- Final project report
- Overall system PDF report
- Hosting requirements report
- Polished project summary report
- Full audit and preservation report
- Frameworks and technology report
- UML use case diagram and layman explanation
- Production readiness package and Module 1 database package

## Main Files

- **open-subhakamana-store-system.html** - Main entry page.

- **subhakamana-store-erp-user-manual.md** - Staff user manual.

- **subhakamana-store-final-erp-ecommerce-report.pdf** - Final report.
- **subhakamana-store-overall-system-report.pdf** - Overall system report.

- **subhakamana-project-summary-report-polished.md** - Presentation-ready project summary.
- **subhakamana-full-audit-preservation-report.md** - Full audit, preservation, refinement, and validation report.

## Stop The System

If a terminal window opens, keep it open while using the system.

To stop the system, close that terminal window or press `Control + C`.
