# Subhakamana Store Export Package

This folder contains the complete local demonstration package for the Subhakamana Store Management System.

## Open First

Start here:

- `OPEN_THIS_FIRST.command`
- or `open-subhakamana-store-system.html`

## Main Platforms

- Admin ERP: `subhakamana-store-final-erp-platform.html`
- Cashier POS: `subhakamana-store-physical-pos.html`
- Customer Website: `subhakamana-store-ecommerce.html`
- Overview Page: `subhakamana-store-simple-overview.html`

## Notes

This is a front-end prototype for local use and demonstration. It uses browser localStorage for demo persistence. Production use will require a backend API, secure authentication, database, payment gateway integration, image storage, and courier API integration.
